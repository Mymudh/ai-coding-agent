# AI Coding Agent

AI Coding Agent is an AI-powered developer assistant designed to help developers generate, analyze, debug, and improve code using Large Language Models.

## Features

- AI Code Generation
- Code Analysis
- Code Debugging and Fixing
- Natural Language Coding Assistance
- LLM-powered Responses
- FastAPI Backend
- React Frontend
- Gemini API Integration
- Developer-focused AI Workspace

## Tech Stack

### Frontend
- React
- Vite
- JavaScript
- CSS

### Backend
- Python
- FastAPI
- Pydantic

### AI
- Google Gemini
- Large Language Models
- Prompt Engineering
- AI Agents
